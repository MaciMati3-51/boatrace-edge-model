## 1. 動機（この文書の前に見た数字）

v4a の時系列外予測（2026-07-19〜11-12、16,896R）を、スタート展示（boatracecsv stt、締切約8.6分前の撮影）の
進入が枠なりか変更ありかで分けた。**この区間は v3・v4 の検証で既に開けてあり、この分割もここで見た**。

| | レース | 2連単 v4−確定市場 | 2連複 | 3連単 |
|---|---:|---:|---:|---:|
| 展示 枠なり | 14,435 | −0.030 | −0.049 | −0.007 |
| 展示 変更あり | 2,245 | +0.001 | −0.026 | **+0.034** |
| 　うち 変更5艇以上 | 282 | +0.061 | +0.033 | +0.072 |

紙上回収率（凍結 v4a 係数、09-10〜11-12、ev_settle>1、各100円）: 2連単 枠なり 104.9%（3,209点）/ 変更あり
**87.5%**（638点）、2連複 111.9% / 103.8%。変更ありのレースでは1レースあたりの点数も多い（0.75 vs 0.57）。
市場は展示の進入を見て動き、モデルは見ていないので、市場が正しく動いた目をモデルが「割安」と誤検出している。

展示の進入は運用の入力CSVに既にある（`exhibition_course`・`exhibition_st`、v1 からの列）。追加の取得は要らない。

## 2. 補正層（`src/v5_entry.py`）

v4 の3段の各条件付き確率に、展示の情報だけで作る項を掛けて正規化する（条件付きロジット、offset = v4 の確率）。

    P'(i)       ∝ P(i)       · exp(x_i · β1)
    P'(j | w)   ∝ P(j | w)   · exp(x_j(w) · β2)
    P'(k | w,s) ∝ P(k | w,s) · exp(x_k(w) · β3)

| 列 | 定義 | 枠なりのとき |
|---|---|---|
| course2〜6 | [展示コース = c] − [枠 = c]。コースの価値の差 | 0 |
| moved_in / moved_out | 内へ動いたコース数 / 外へ押し出されたコース数 | 0 |
| deep_c1 / deep_c23 | 展示1コース（2・3コース）の艇 × レース内の内への移動の合計（上限4）。深い起こし | 0 |
| st_rel / st_flying | 展示ST（−0.10〜0.40 に切る）のレース内平均との差 / 展示でフライング | **0 ではない**（ST 版のみ） |
| adjacent_to_winner / outside_winner（2・3着段） | 1着艇の隣か・すぐ外か の、展示コースと枠の差 | 0 |

- 進入の列だけの版（**entry**、1着段9列・2/3着段11列）は、展示が枠なりなら v4 と同じ確率を返す
- ST を足した版（**entry_st**）は全レースで確率が動く。v2 の時点（4,224R）では展示STの上乗せ効果は0と区別できなかった
- リッジ 1.0（対数尤度の和に対して）、L-BFGS。コースが 1〜6 の並べ替えになっていないレース（欠場など）は補正しない
- 入力は stt を締切前60分以内に撮ったものだけ（od2 の板と同じ条件）

## 3. 検証（1回だけ。`src/v5_entry.py evaluate`）

- **係数の推定**: 2026-01-01〜07-18。v4 と同じ設定で学習を 20251231 で打ち切ったモデル（`data/models/live_v4_y25/`、
  学習 20190901〜20251231）の時系列外予測。**この区間は封印期間に入るが、使うのは係数の推定だけで、評価値は出さない**
  （v3・v4 も封印期間を学習に使っている。metadata の `sealed_period_used_for: training only`）
- **比較**: 2026-07-19〜11-12 の v4a の凍結済み時系列外予測（`prereg/live_v4_freeze.json` のハッシュで照合）に補正を掛け、
  同じレースで v4 と比べる。日単位ブートストラップ95%。前半 07-19〜09-14 / 後半 09-15〜11-12
- **判定**（下の JSON が機械判定の入力）:
  1. **entry を採用**: entry − v4 の log-loss が **2連単・3連単の両方で** 95%上限 < 0、かつ前半・後半とも点推定 < 0
  2. **ST も採用**: 1 を満たし、かつ entry_st − entry が同じ条件を満たす
  3. どちらも満たさなければ v5 は作らない
- 併記（判定に使わない）: 1着・2連複・3連複、変更あり／枠なりの内訳、確定市場との差（3連単を含む）、
  紙上回収率（市場合成と変動補正を 07-19〜09-09 で v4・v5 とも推定し直し、09-10〜11-12 の ev_settle>1 を各100円）

```json
{"decision_pools": ["2連単", "3連単"]}
```

### 予想（結果を見る前に書く）

変更ありのレース（約13%）で v4 が枠なりのレースより確定市場に対して 0.03〜0.04 悪い分を半分取り戻せれば、全体で
2連単・3連単とも −0.002 前後。95%区間の幅は全体で約 ±0.001 と見込むので、効果が半分以下なら判定を通らない。
枠なりのレースは entry では1円も動かない（構造上）。

## 4. 採用した場合（凍結と前向き検証）

1. 最終係数を 2026-01-01〜11-12 の時系列外予測全部（live_v4_y25 ＋ live_v4a の2本）で推定する（`v5_entry.py fit`）
2. 市場合成と変動補正を、補正後の確率で 2026-07-19〜11-12 の時系列外予測から推定し直す
3. v4 の凍結モデル（`data/models/live_v4/model.pkl`）は変えない。ハッシュ・係数を `prereg/live_v5_freeze.json` に残す
4. **凍結は 20261113 以降のデータを取得する前に行う。** 前向き検証は v4 の主判定と同じ 20261113〜20270112 で1回。
   v5 − v4（2連単・3連単・2連複）と v5 − 確定市場（3連単）、紙上回収率。v4 の主判定の結論は v5 の結果で変えない

## 5. 運用

入力CSVの `exhibition_course`・`exhibition_st` を使う（既に転記している列）。空欄・並べ替えになっていない場合は補正なし＝v4。
