## 結論

1. **確率の精度は大きく上がった（前向きで確定）。** v2 比で 1着 −0.034 / 2連単 −0.063 / 2連複 −0.049
2. **v3 はオッズを見ずに、2連単・2連複の確定市場より当たる（前向きで確定）。** プロジェクト開始以来、
   市場を log-loss で下回ったのは初めて。「モデルを良くしても市場に追いつくだけ」（9/9）は、少なくとも
   この2つの薄いプールでは成り立たなくなった
3. **2連複の紙上回収率は 113.9%、区間の下限 101.8% で事前登録の基準を超えた。** 2連単は未確立
4. これは収益性の証明ではない。理由:
   - 下限は 100% を 1.8pt 上回るだけ。2券種を判定しているので、片方が偶然超える確率は名目の2倍
   - 各100円・自分の賭けがオッズを動かさない前提。2連複プールは薄く、金額を増やすと自分でオッズを下げる
   - 上位10件の的中を除くと 94.9%。51日・1,741点では裾の影響がまだ大きい
   - 返還（F・L・欠場）のレースは標本から外している
