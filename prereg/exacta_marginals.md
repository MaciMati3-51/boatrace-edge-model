# 2連単の着順別オッズ集約（2026-11-21）

同じ艇を1着とする5点、または2着とする5点に入った支持を足すと、1点ずつのオッズよりばらつきが小さくなると考えた。v4 の合成式に、1着艇・2着艇それぞれの「板の周辺確率 ÷ モデルの周辺確率」の対数を1列ずつ加える。追加係数がゼロなら元の式になる。

係数は v4a の時系列外予測の 2026-07-19〜09-09 で決める。比較用の v4 合成器も同じ標本で推定する。09-10〜11-12 の全期間で2連単 log-loss の対応差を取り、日単位 bootstrap 95% 区間の上限が0未満で、10-09までと10-10以降の両方で差が負なら候補に採用する。最大確率の1点の的中率と、従来の購入ルール（確定時の推定期待値が1を超える全点に各100円）の紙上回収率も併記する。閾値は探索しない。

この期間は v4 の成績が既知の過去検証。11-13以降の前向き検証は対象外。再現はリポジトリ直下で `.venv/bin/python src/exacta_marginals.py`。

## 第2実験（第1実験の結果確認後に設計）

撮影オッズを0.1倍刻みに切り下げるモデルを仮定し、表示された30点と整合する最小の整数総票数 N を推定する。全票が公約数を持つ場合などは過小に出るため、板の厚さの代理指標として使う。学習標本における推定値の中央値を M とし、重み N/(N+M) で薄い板・厚い板の2つの市場係数を補間する。推定できない板には中央値を割り当てる。比較標本と採用基準は第1実験と同じ。第1実験と同じ既知期間を再利用するので探索結果として扱う。

## 第3実験（第2実験の結果確認後に設計）

購入判定に使う確定オッズの予測を対象にする。的中確率は v4 合成に固定し、従来の変動補正の3列（定数、モデルと市場の対数確率差、市場の対数確率）それぞれに N/(N+M) を掛けた3列を追加する。較正期間・検証期間は上記と同じ。的中目で log(予測確定倍率 / 実際の払戻倍率) の二乗誤差を比較し、対応差の日単位95%区間が負、かつ両半期で負なら変動補正の研究用候補とする。確率精度の向上とは別の判定。購入閾値は従来どおり1で、紙上回収率は副指標。

## 結果

時系列外予測のうち、締切前60分以内に展示タイムを確認でき、K文書の値と6艇とも一致し、2連単の30点と通常払戻が揃ったレースを使用した。係数推定 5,198R、検証 6,353R。票数を逆算できたのは推定期間 5,015R、検証期間 6,097R。推定期間の中央値は1,069票。表示刻みと75%払戻の仮定の下で、最も高い倍率の買い目に1〜128票入った場合を試し、30点すべての票数の和が総票数と整合する最小値を使った。実際の売上票数との照合はしていない。

| 実験 | 同じ標本で再推定した v4 式 | 候補 | 対応差の日単位95%区間 | 判定 |
|---|---:|---:|---:|---|
| 着順別の市場確率を追加（2連単 log-loss） | 2.462368 | 2.462200 | [−0.000845, +0.000500] | 見送り |
| 票数で市場合成を調節（2連単 log-loss） | 2.462368 | 2.462118 | [−0.000651, +0.000152] | 見送り |
| 票数で確定オッズを補正（的中目の対数倍率の平均二乗誤差） | 0.091501 | 0.089981 | [−0.002034, −0.001023] | 紙上比較用に採用 |

第3実験は当時の凍結済み v4a の的中確率を全方式で使った。凍結済みの変動補正と比べても誤差は 0.091465 → 0.089981（約1.6%減）。差は前半 −0.00159、後半 −0.00140。各100円の紙上回収率は凍結 v4a が99.5%（3,754点）、新補正が105.2%（3,937点、95%区間 89.2〜126.6%）。予測後に賭け金がオッズを変える影響は含まない。収益性の確認は新しいレースで行う。

## 再現と紙上予測

各実験はローカルの凍結予測と取得済みCSVを使用する。数値の詳細は `exacta_marginals_result.json`、`exacta_liquidity_result.json`、`exacta_settlement_result.json`。再現用のコマンドは次のとおり。

```bash
.venv/bin/python src/exacta_marginals.py
.venv/bin/python src/exacta_liquidity.py
.venv/bin/python src/exacta_settlement.py evaluate
.venv/bin/python src/exacta_settlement.py fit
```

最終候補は 2026-11-12 までの時系列外予測11,551Rで変動補正を再推定した。中央値1,114.5票、係数と適用先モデルは `exacta_settlement_coefficients.json` に保存した。この最終係数の精度は今後のレースで検証する。

通常の v4 の `predict` で生成したディレクトリに対して次を実行すると、2連単の全点について従来の判定と新補正の判定が同じCSVに出る。

```bash
.venv/bin/python src/exacta_settlement.py score --v4-dir "$V4_PREDICTION_DIR" --out exacta_paper.csv
```

`p_final` は v4 の合成確率、`estimated_votes` は撮影時の推定票数（空欄は中央値で補正）、`expected_settled_odds` は的中時の推定確定倍率。その積 `ev_settle` が1を超えた目に `paper_candidate` が立つ。従来値は `v4_ev_settle` と `v4_paper_candidate`。今後は撮影時に両判定を記録し、予定済みの v4 前向き評価の時点で、新補正の誤差と紙上回収率も別集計する。
