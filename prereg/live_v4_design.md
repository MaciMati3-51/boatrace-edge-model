## 4. 検証（事前登録）

共通: v3・v4 とも再学習・係数変更なし。標本は v3 の前向き検証と同じ条件・同じ手順（正常6艇完走、展示タイムが
締切前60分以内に出ていて K文書と一致、通常払戻1件、板が完全。2連複は2連単板も完全）。v3 と v4 は同じレースで比べる。
実行は `src/evaluate_prospective_v4.py`（結果ファイルがあれば止まる）。

### A. 既に開けた区間での比較（副）: `evaluate_prospective_v4.py check` — 1回だけ

**対象**: 20260910〜20261112。主に見るのは 20260923〜1112（7,046レース）。
**この区間は v3 の前向き検証（2026-11-13）で既に開けてあり、v3 の成績を知っている。** v4 の設計（§2 の採否）には
使っていない。v4a は v3 と同じ 20260909 までで学習するので、同じ土俵の比較になる。
**位置づけ**: v4−v3 の log-loss（Q1）と確定市場との差（Q2）は、v4 の選択に使っていない標本での1回きりの測定として読む。
**紙上回収率（Q4）は確認ではない**: v3 の買い目と大きく重なる同じ51日を2度目に見ることになる。記録はするが、
収益性の根拠には使わない。

### B. 前向き検証（主）: `evaluate_prospective_v4.py prospective`

**対象**: 20261113 〜 取得できる最新日（この文書より後に初めて取得する）。
**打ち切りの規則**: 主判定は **20261113〜20270112 の2か月**が揃った時点で1回だけ実行する。それより前に途中経過を
見るための実行はしない（結果ファイルがあれば止まる仕組みで強制する）。v3 の凍結系列は同じデータで別に回し続ける。

| | 指標 | 判定（A は 20260923〜、B は全期間で） |
|---|---|---|
| Q1（主） | v4 − v3 の log-loss（1着・2連単・2連複）、日単位bootstrap 95% | 2連単・2連複の上限 < 0 なら「v4 が良い」 |
| Q2 | v4 単体 − 確定市場（2連単・2連複・3連単・3連複） | 券種ごとに上限 < 0 なら「v4 単体が確定市場を下回る」。3連複は正規化子の不確かさ（±0.009）を併記 |
| Q3 | v4 合成 − 確定市場、v4 合成 − v3 合成（2連単・2連複） | 上限 < 0 なら「下回る」 |
| Q4 | 紙上回収率（各100円）: v4 ルール・v3 ルールとも `ev_settle > 1`。閾値 1.1・1.2、**撮影オッズ10倍未満だけ**の副指標も記録 | v4 ルール（閾値1）の95%下限 > 100% なら「紙上で100%超」。それ以外は「未確立」 |

「撮影オッズ10倍未満」は v3 の事後点検（2連複の10倍未満 973点が 110%前後、裾に頼らない部分）から立てた副指標。
B で初めて事前登録つきで測る。

**事前の見込み**（外れたら見込みが間違っていたと書く）: Q1 は開発区間の 6〜9割（1着 −0.003 前後、2連単 −0.006 前後）。
Q2 の3連単は −0.005〜−0.012。Q4 の点数は v3 より増える（モデルが市場から離れるほど `ev_settle > 1` が増える）が、
増えた分が本物かは分からない。

**結論しないこと**: 実際に賭けて勝てるか。紙上回収率は自分の賭けがオッズを動かさない前提で、2連複プールは薄い。
3連単・3連複は板が無いので、log-loss で市場を下回っても回収率は測れない。

結果は `prereg/live_v4_check_result.md`・`prereg/live_v4_prospective_result.md` に書く。この文書は書き換えない。

## 5. 運用（スクショからの予測）

v3 の手順に `v4_meta.py` が1行増える。入力CSV・オッズCSVは v2・v3 と同じ形式。

```bash
.venv/bin/python src/download_lzh.py --start 2026-11-16 --end 2026-11-17      # 前日の K と当日の B
uv run --no-project --python 3.12 --with lhafile python src/extract_lzh.py
.venv/bin/python src/import_bk_range.py 20261116 20261117
.venv/bin/python src/parse_b_meta.py
.venv/bin/python src/v4_meta.py                                                # 進入固定・レース種別
.venv/bin/python src/live_market_v4.py predict \
  --input race.csv --odds odds.csv --out prereg/live_v4_YYYYMMDD_JJ_RR
```

`final.csv` は 2連単・2連複の `ev_settle`（確定オッズでの期待値）と `paper_candidate`（その >1）。
`fundamental.csv` は 1着・2連単・2連複・3連単・3連複の確率（オッズ不使用）。撮影は締切9〜10分前。

**注意**: `extract_lzh.py`・`parse_kb.py`・`import_bk_range.py` で 2019-07 より前を本体に取り込まないこと。
古い年は `extract_lzh_ext.py` → `build_history_ext.py` で `data/raw/txt_ext/`・`data/parsed/ext/` に分けてある。
