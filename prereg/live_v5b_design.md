## 2. 仕様（`src/v5b_course.py`、補正の式は `src/v5_entry.py`）

v5 の entry 版（展示STなし）の列に3列を足す。3段とも同じ3列。

    d_m = logit(r_m(選手, 展示コース)) − logit(r_m(選手, 枠番のコース))     m = 1着率・2連対率・3連対率
    r_m(選手, c) = (その選手が本番の進入 c で出た走の m の回数 + 20·全国のコース c の率) / (走数 + 20)

- 走数・回数は K の `entry_course`（本番の進入）から、**対象日より前**の出走だけで集計（as-of 結合、同日は入らない。
  `tests/test_v5_entry.py` で、対象日以降の結果を消しても値が同じことを確認）。欠場は除き、F・L は着外
- 全国のコース別の率は 2025-12-31 までの出走で固定
- 展示が枠なりの艇は 0。**展示が枠なりのレースは v4 と同じ確率**（展示STを使わないので）
- リッジ 1.0、L-BFGS（v5 と同じ）
- 推定に使う stt: 締切前60分以内の撮影 ＋ 撮影時刻の無い後追い取得（`取得日時 = backfill-from-daily`）。
  検証・運用は締切前60分以内の撮影だけ（od2 と同じ条件）

### 予想（結果を見る前に書く）

変更ありのレース（13%）で 3連単の市場との差 +0.034 のうち3分の1を取れれば、全体で −0.004。v5 が取れたのは約1割（全体 −0.0005）。
選手別の情報が市場の優位の主因なら足切りを通る。通らなければ、市場の優位は展示の別の情報（隊形・起こしの深さ・展示航走の
足など、stt に無いもの）にあると読む。
