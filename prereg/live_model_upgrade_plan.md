# スクショ3種を使う予測モデルへの更新方針

2026-09-12。実装・再学習は未完了。既存の凍結予測は変更しない。

## 目的と構成

出走表と過去履歴、締切前の直前情報から着順確率を推定する。券種ごとの直前オッズから市場確率を求め、学習済み合成器で最終確率を作り、期待値を判定する。対象は既存の1着・2連単・2連複。情報を追加するだけでは収益性の証明にならない。

## 実装順

1. スクショ転記入力を共通化する。レースID、艇番、出走表、直前情報、券種別全オッズ、画像パス、オッズ更新時刻、取得時刻、締切予定時刻を保持。欠損と未対応項目を区別する。
2. 現行の出走表・履歴モデルを比較対象として残し、展示タイム・レース内順位・平均との差を追加したモデルを作る。過去のbase.parquetにはこれらの列がある。対象レースではスクショ由来の展示タイムを使う。結果文書の実ST・実進入は追加しない。
3. 展示ST、展示進入、チルト、部品交換、気象は保存を開始する。これらは同じ定義の過去入力と結果が揃うまで、学習済みの効果として使用しない。手動の係数は足さない。
4. オッズ合成は2連単・2連複それぞれのデータで時系列外予測を使って学習・評価する。既存の3連単由来係数の移植を、検証済みの本番合成器とは扱わない。過去の確定オッズと実運用の締切前オッズの違いを明記する。
5. 改善判定は開発期間の時系列分割で行い、封印期間は改善選択に使わない。現行、展示追加、市場のみ、合成を比較。モデル確率の精度と、市場に対する追加情報、回収率を区別する。
6. 更新後の入力仕様、モデル版、学習期間、選択ルールを固定して前向き検証する。締切後に生成した予測は事前予測に数えない。

## 現状の結論

今の前向きモデルは過去成績だけでなく対象レースの出走表も使う。直前情報を欠くことだけで収益性がないとは結論できない。過去研究側には展示タイムを使ったモデルが存在するため、直前予測への接続と同条件での比較を優先する。スクショ数件だけでは直前情報全項目やオッズ合成を信頼できる形で学習するには足りない。
