## 1. v2 からの変更

| # | v2 | v3 |
|---|---|---|
| 1 特徴量 | 出走表9列＋選手の通算5列＋会場×枠の1着率＋展示タイム3列（計18列/艇） | 約100列/艇（`src/v3_features.py`）。選手の直近90日・365日・通算、**選手×枠**の成績・ST・決まり手・1号艇を逃がす率・前付け頻度、枠の有利不利を引いた残差、**モーター使用期間内**の成績と展示、今節（同会場の直近7日）、休み明け・Fからの日数、レース種別・締切時刻 |
| 2 モデル | 6艇を横に並べた6クラス分類（枠ごとに別の木） | **1艇1行・全艇共通の木・レース内 softmax**（条件付きロジットの勾配ブースティング）。1着段は6クラス分類と幾何平均（0.6 / 0.4） |
| 3 2着段 | 1着艇を入力にした6クラス分類 | 1着艇を所与とした残り5艇の softmax（艇単位）。候補艇・1着艇・その差・全艇の主要特徴 |

展示タイム以外の直前情報（展示ST・展示進入・チルト・気象）は v2 と同じく使わない。
K文書の気象を足す実験は 1着 −0.0013 ±0.0009 だったが、締切前の値との対応付けが要るので見送った。

**特徴量の時刻安全性**: 全て「対象日より前の結果」だけから作る（日単位。同日の別レースは見ない）。
対象日以降の結果を全て消して作り直しても、対象日の特徴量が全列一致することを実データ（20250301、1,008艇）と
合成データ（`tests/test_live_v3.py`）で確認した。本番経路（当日のB＋前日までの結果）とキャッシュ経由の予測は
20260910 の129レースで完全一致（成績は見ていない）。

## 4. 前向き検証（事前登録）

**対象**: 20260910 〜 取得できる最新日。v2・v3 とも再学習・係数変更なし。
**主判定の区間**: 20260923 以降（この文書より後に初めて取得する）。20260910〜0922 と全体も併記する。
**データ**: 公式 B/K（mbrace）、boatracecsv の tkz・od2（取得日時が予定締切前60分以内）。
**標本**: 正常6艇完走、展示タイムが締切前に出ていて K文書と一致、通常払戻1件、板が完全（2連複は2連単板も完全）。
v2 と v3 は同じレースで比べる。v2 の履歴特徴は v2 が見ていた範囲（20220701〜）のデータで作る。
**実行**: `src/evaluate_prospective_v3.py`（引数なし。1回だけ。結果ファイルがあれば止まる）。

| | 指標 | 判定（主判定の区間で） |
|---|---|---|
| Q1（主） | v3 − v2 の log-loss（1着・2連単・2連複）、日単位bootstrap 95% | 2連単・2連複の上限 < 0 なら「v3 が良い」 |
| Q2 | v3 単体 − 確定市場（券種別） | 上限 < 0 なら「v3 単体が確定市場を下回る」 |
| Q3 | v3 合成 − 確定市場、v3 合成 − v2 合成 | 上限 < 0 なら「v3 合成が確定市場を下回る」 |
| Q4 | 紙上回収率（各100円）: v3 ルール・v2 ルールとも `ev_settle > 1`。閾値 1.1・1.2 も記録 | v3 ルール（閾値1）の回収率の95%下限 > 100% なら「紙上で100%超」。それ以外は「未確立」 |

**結論しないこと**: 実際に賭けて勝てるか。紙上回収率は自分の賭けがオッズを動かさない前提で、2連複プールは薄い。
撮影から締切までの変動は補正しているが、補正は 0719〜0909 の推定。Q4 が「紙上で100%超」になっても、
次の段階は少額の実地確認であって、結論ではない。

結果は `prereg/live_v3_prospective_result.md` に書く。この文書は書き換えない。

## 5. 運用（スクショからの予測）

v2 と違い、出走表は当日の公式 B から取る（モーター番号・ボート番号・レース種別が要る）。前日の結果も取り込む
（今節の成績を使うので、前日ぶんが無いと精度が落ちる）。入力CSV・オッズCSVは v2 と同じ形式。

```bash
.venv/bin/python src/download_lzh.py --start 2026-11-13 --end 2026-11-14      # 前日の K と当日の B
uv run --no-project --python 3.12 --with lhafile python src/extract_lzh.py
.venv/bin/python src/import_bk_range.py 20261113 20261114
.venv/bin/python src/parse_b_meta.py
.venv/bin/python src/live_market_v3.py predict \
  --input race.csv --odds odds.csv --out prereg/live_v3_YYYYMMDD_JJ_RR
```

`final.csv` の `ev_settle` が確定オッズでの期待値、`paper_candidate` はその >1。撮影は締切9〜10分前。
