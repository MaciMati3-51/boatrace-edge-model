## 読み方

1. **v4 は v3 より確率が良い**（2連単・2連複、選択に使っていない標本で確認）。伸びは小さい（v3 が v2 に付けた差の約 1/10）
2. **「3連単の確定市場を下回る」は開発区間だけの結果で、直近の標本では成り立たない。** 開発区間（2024-07〜2025-07）
   −0.0125 → 2026-07〜09 −0.0056（0を跨ぐ）→ 2026-09〜11 +0.0048。原因は切り分けていない（開発区間での選び直しの
   楽観／3連単の市場が直近で鋭くなった／正規化子 1.3364 を全期間一定と置いたこと、のどれもあり得る）
3. 2連単・2連複・3連複では市場との差が v3 より広がった。薄いプールほど差が大きい、という v3 の所見と同じ並び
4. 収益性は未証明のまま。主判定は §4-B（20261113〜20270112 が揃ってから1回）
